# Tic-Tac-Toe Game using Python

A simple two-player Tic-Tac-Toe game built using Python and Tkinter. The game provides a graphical interface where two players can take turns, compete against each other, and see the result automatically.

## Features

- Two-player gameplay (X and O).
- Interactive 3×3 game board.
- Automatic player turn switching.
- Win detection across rows, columns, and diagonals.
- Draw detection when all cells are filled.
- Highlights the winning combination in green.
- Displays the game result using message boxes.

## Technologies Used

- Python
- Tkinter (GUI library)

## Requirements

- Python 3.x
- Tkinter (usually included with standard Python installations)

No additional external libraries are required.

## How to Run

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd tic-tac-toe
   ```

3. Run the Python file:

   ```bash
   python tic_tac_toe.py
   ```

## How to Play

1. Launch the game.
2. Player X starts first.
3. Players take turns clicking an empty cell on the 3×3 board.
4. The first player to get three marks in a row, column, or diagonal wins.
5. If all nine cells are filled without a winner, the game ends in a draw.
